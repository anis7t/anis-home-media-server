# Walkthrough — Google-Authenticated One-Time Admin Access (OTP) & Static PIN Decommission

## Executive Summary

The MediaServer administrative authentication architecture has been redesigned and hardened. The permanent static Admin PIN mechanism has been decommissioned across the entire stack (PostgreSQL database, Rust/Axum backend, React 19 SPA frontend, and Flutter Android/TV client) in favor of a secure, short-lived (5-minute), single-use One-Time Admin Access Code (OTP).

The longstanding defect where the UI claimed a 4-digit code while the system required 6 digits has been resolved throughout the repository: exactly 6 discrete numeric digits are enforced with auto-advance, backspace navigation, paste support, and automatic submission.

---

## Deliverables & Key Changes Across the Stack

### 1. Database Schema & Migration (`rust/src/db.rs`)
- **New Table `admin_access_otps`:**
  - `id BIGSERIAL PRIMARY KEY`
  - `admin_user_id BIGINT REFERENCES users(id) ON DELETE CASCADE`
  - `admin_email VARCHAR(255) NOT NULL`
  - `otp_hash VARCHAR(64) NOT NULL` (Salted HMAC-SHA256 digest; plaintext code is NEVER stored)
  - `salt VARCHAR(32) NOT NULL` (Cryptographically secure 128-bit random salt)
  - `created_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP`
  - `expires_at TIMESTAMPTZ NOT NULL` (Strict 5-minute lifespan: `CURRENT_TIMESTAMP + INTERVAL '5 minutes'`)
  - `used_at TIMESTAMPTZ` (Single-use redemption timestamp)
  - `used_by_device_id VARCHAR(255)` & `used_by_ip VARCHAR(64)`
  - Partial index `idx_admin_access_otps_active ON admin_access_otps (expires_at) WHERE used_at IS NULL` for performant active-code lookups.
- **Data Cleanup & Static PIN Purge:**
  - Database startup migration automatically purges `settings WHERE key = 'admin_pin'` and synthetic user accounts (`google_sub = 'sub_admin_pin'`).

### 2. Rust Backend Service & Endpoints (`rust/src/`)
- **Models (`rust/src/models/identity/auth.rs`):**
  - `AdminOtpGenerateResponse`: `{ success: bool, access_code: String, expires_in_seconds: i64, expires_at: String }`
  - `AdminOtpVerifyRequest`: Accepts `{ otp: Option<String>, code: Option<String>, pin: Option<String>, admin_email: Option<String> }`
  - `AdminOtpVerifyResponse`: `{ success: bool, admin: bool, method: String, expires_in_seconds: i64, token: Option<String> }`
  - `AdminOtpRevokeResponse`: `{ success: bool, revoked_count: u64 }`
- **Core Security Logic (`rust/src/services/identity/auth_service.rs`):**
  - **Generation (`generate_admin_otp`):** Requires an active, authenticated Google administrator session (`role == "admin"`). Validates configured administrator allowlist. Enforces a 3-second generation rate-limit to prevent rapid spamming.
  - **Single-Use Redemption (`verify_admin_otp`):** Constant-time cryptographic comparison (`subtle::ConstantTimeEq`) against active, unexpired, unredeemed OTP hashes. Atomically marks the record as redeemed (`UPDATE ... SET used_at = CURRENT_TIMESTAMP WHERE id = $1 AND used_at IS NULL`) to prevent race conditions and replay attacks.
  - **Anti-Bruteforce & Lockout:** Tracks failed verification attempts per IP in an in-memory sliding window. Implements lockouts with exponential delays upon repeated failed attempts.
  - **Revocation (`revoke_admin_otp`):** Allows an administrator to instantly invalidate all active unredeemed OTPs generated by their account.
- **REST Endpoints & Route Decommissioning (`rust/src/routes/identity/`):**
  - `POST /api/admin/otp/generate`: Generates a 5-minute single-use OTP for the Google admin.
  - `POST /api/admin/otp/verify`: Atomically validates and redeems a single-use OTP.
  - `POST /api/admin/otp/revoke`: Revokes all outstanding OTPs for the authenticated admin.
  - `POST /api/auth/login-pin`: Permanently returns `410 Gone` with migration notice.
  - `POST /api/admin/pin`: Permanently returns `410 Gone` with migration notice.
  - `POST /api/admin/verify`: Legacy verify endpoint accepts either an active Google session or valid OTP code; static PINs are refused (401 Unauthorized).

### 3. React 19 Frontend SPA (`web/src/`)
- **Administrator Security Card (`web/src/features/account/AccountPage.tsx`):**
  - Exclusively visible to verified Google administrators.
  - One-click "Generate Admin Access Code" action.
  - Displays a 6-cell monospace card with active countdown timer (minutes & seconds), visual progress bar, "Copy Code" action with copied feedback, and "Revoke Code" emergency invalidation.
- **6-Digit Discrete OTP Input Experience:**
  - Redesigned `AdminPinSignInModal.tsx` and `AdminPinModal.tsx` from single inputs to 6 discrete numeric input cells.
  - **Auto-advance:** Typing a digit automatically focuses the next cell.
  - **Backspace navigation:** Pressing Backspace clears the cell and shifts focus to the previous cell.
  - **Paste Support:** Pasting a 6-digit code (e.g. from clipboard) automatically distributes digits across all 6 slots and auto-submits.
  - **Mobile Keypad:** Configured with `inputMode="numeric"` and `pattern="[0-9]*"`.
- **Session & Header Hardening:**
  - Removed `X-Admin-Pin` header injection across all API clients (`account.ts`, `manage.ts`, `uploadApi.ts`).
  - Purged `ms_admin_pin` from `sessionStorage` in `TranscodeDashboardPage.tsx` and `ManagePage.tsx`.
  - Removed obsolete "Change PIN" modal and buttons from `ManagePage.tsx`.
  - Updated `DeleteConfirmationModal.tsx` and `DevicesPage.tsx` to 6-digit access codes.
