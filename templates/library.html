Privacy Policy

Anis' Media Server is a private, self-hosted application. It does not collect, transmit, or share personal data with any third party.

Playback progress and connected device information are stored locally in a SQLite database on the server and are never uploaded externally.

Remote access is provided via a Cloudflare Quick Tunnel solely for convenience. No analytics or tracking scripts are embedded in this application.
